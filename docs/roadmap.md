# Roadmap

## <u>V1 - MVP</u>
- [ ] Registro y autenticación.
- [ ] Edición del nombre del usuario.
- [ ] Población de tabla de ingredientes a través de una API externa.
- [ ] Operaciones CRUD de neveras.
  - [ ] Asociación de ingredientes a una nevera, ya sea introducciendo o seleccionando un ingrediente.
- [ ] Operaciones CRUD de recetas.
  - [ ] Asociación de ingredientes de una nevera a una receta.

## <u>Futuras versiones</u>
- [ ] Búsqueda de recetas a través de una API externa.
- [ ] Guardado de recetas de esta API en las recetas de un usuario.
- [ ] Lista de la compra para ingredientes que falten para una receta.
- [ ] Sugerencia de receta con los ingredientes disponibles.

- [ ] Planificación semanal, asignación de recetas a días/comidas.
- [ ] Notificaciones para recordatorio de lista de la compra.
- [ ] Recetas favoritas, las más asignadas en la planificación.

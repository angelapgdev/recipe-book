# Casos de uso

## <u>V1 - MVP</u>

### Actor: Usuario

- **CU1**: Registrarse.
- **CU2**: Iniciar sesión.
- **CU3**: Crear nevera.
- **CU4**: Consultar nevera.
- **CU5**: Editar nevera.
- **CU6**: Eliminar nevera.

- **CU8**: Seleccionar ingrediente para una nevera.
- **CU9**: Eliminar ingrediente de una nevera.
- **CU10**: Crear receta seleccionando ingredientes.
- **CU11**: Consultar receta.
- **CU12**: Editar receta.
- **CU13**: Eliminar receta.
